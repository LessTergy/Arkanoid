## Правило обновления

После выполнения задачи отмечается checkbox только в файле её этапа. После прохождения Gate обновляются статус этапа и ссылка на текущий этап в этом файле. Если реализация отклоняется от плана, сначала фиксируется новое решение в `SCOPE.md` или `ARCHITECTURE.md`, затем корректируется затронутый этап.
