## Как читать каталог

Карты точно извлечены из [Level::getLayout](../../src/level.cpp#L224). Это раскладки клона; их совпадение с аркадным оригиналом не проверялось. Видимые номера — 1…32, исходные индексы — 0…31. Строки и колонки в картах соответствуют массивам, в том числе начальные пустые строки.

Каждая строка содержит 13 символов. Центр ячейки (c,r): **x = 16 + 16c, y = 28 + 8r**, c,r начинаются с 0. Символы:

| Символ | Тип | Очки |
| --- | --- | --- |
| `_` | Пустая ячейка | — |
| `0` | Белый | 50 |
| `1` | Оранжевый | 60 |
| `2` | Голубой / Cyan | 70 |
| `3` | Зелёный | 80 |
| `4` | Красный | 90 |
| `5` | Синий / Blue | 100 |
| `6` | Розовый | 110 |
| `7` | Жёлтый | 120 |
| `8` | Серебряный | 50 × раунд |
| `9` | Золотой, неразрушимый | 0 |

Серебро: **2 + floor(раунд/8) HP**. «Попадания» — сумма начальных HP разрушаемых блоков, без промахов/отскоков от золота. «Очки» — только полная очистка блоков, без капсул и Break. «Цели» — цветные + серебро. Комментарии о геометрии и короткие названия — интерпретация для дизайнера, не авторские названия или измеренная сложность.

## Как меняется задача

- Многоцелевая очистка: раунды 1, 2, 4, 7, 13, 15, 24.
- Золотые барьеры и ограниченный доступ: 3, 8, 12, 20, 21, 26, 29, 32.
- Повторные удары по серебру: 5, 11, 23, 27, 31.
- Самая маленькая цель по числу разрушений: раунд 8, 7 блоков; следующий лабиринт с минимумом целей — раунд 12, 8 блоков.
- Самое большое число разрушаемых целей: раунд 15, 148. Самая большая сумма HP: раунд 23, 310.
- Полностью без капсул: раунд 11, все цели серебряные. В остальных фактическое число капсул зависит от одного мяча, свободного слота и уничтожения именно мячом.

Кампания чередует геометрические и ресурсные задачи. Серебряная стойкость растёт ступенями, но количество целей и сумма HP не растут монотонно. Дополнительная оценка темпа и экономики — в [балансе](02-balance-and-powerups.md).
